# Нұсқаулық талаптарына сәйкестік

Дереккөз: «Жасанды интеллект негіздері» пәні бойынша жобаға арналған әдістемелік нұсқаулар (ҚазҰҚПУ, 2026).
Белгілер: ✓ — орындалды, ◐ — жартылай орындалды, ✗ — әлі жоқ. «Кім» бағаны жұмысты кім істейтінін көрсетеді.

## 2. Жобаға қойылатын талаптар

| Талап | Күйі | Дәлел немесе не жетіспейді | Кім |
| --- | --- | --- | --- |
| Нақты проблема және мақсатты аудитория | ◐ | README-де сипатталған (5–11 сынып оқушысы мен әдебиет мұғалімі). Есепте өзектілікті дәлелдеу керек: сандар мен дереккөздер. | топ |
| ЖИ технологиясының атауы мен міндеті | ✓ | Gemini (OpenAI-үйлесімді API), `src/lib/ai/`, README «Үш байланысқан ЖИ функциясы» | — |
| Кемінде 3 өзара байланысты функция | ✓ | тапсырма генераторы → ашық жауапқа кері байланыс → «Сұрағың бар ма?» чаты | — |
| Кіріс → өңдеу → шығыс сызбасы | ✓ | `docs/io-diagram.md` | — |
| Кемінде 10 тестілік жағдай | ◐ | 12 ЖИ жағдайы, 18 unit-тест, 16 браузерлік қадам. Бірақ ЖИ жағдайлары әзірге демо режимде жүгірді: шын Gemini кілтімен қайта жүгіртіп, «қолмен бағалау» жолдарын толтыру керек. | кілт — сіз, жүгірту — мен |
| Кемінде 2 кемшілікті түзету дәлелі | ✓ | `docs/testing.md`: 5 кемшілік, себебі мен түзетуі | — |
| Топ мүшелерінің үлесі | ✗ | 3–5 адамның аты мен әрқайсысы не істегені керек | топ |
| Өнімнің шектеулері | ✓ | README «Әлі жасалмаған», «Авторлық құқық» | — |

## 4. Кезеңдер

| Кезең | Күйі | Ескерту |
| --- | --- | --- |
| 1. Проблема | ◐ | есепте жазылады |
| 2. Кемінде 3 ұқсас шешімді салыстыру | ✗ | Мысалы: Kahoot/Quizizz, Bilimland/iMektep, ChatGPT-ті тікелей қолдану. Кесте: не істейді, қазақ тілі, ЖИ, мұғалім бақылауы, бағасы. |
| 3. Технологияны таңдау негіздемесі | ◐ | Модельдер (Gemini, Groq, OpenAI) кодта бір қалыпта, бірақ салыстыру кестесі жазылмаған |
| 4. Жобалау | ✓ | `docs/io-diagram.md`, пайдаланушы сценарийлері |
| 5. Прототип | ✓ | жұмыс істейтін веб-қосымша |
| 6. Тестілеу | ◐ | шын ЖИ-мен нәтиже керек (жоғарыдағыдай) |
| 7. Қорғау: есеп, презентация, демо | ✗ | төменде |
