# Тестілеу

Үш деңгей:

1. **Unit-тесттер** (`npm test`, `src/lib/logic.test.ts`) — ЖИ-сіз ережелер мен ЖИ жауабының схемасы.
2. **ЖИ тест жағдайлары** (`npm run ai:eval` → [ai-eval-results.md](ai-eval-results.md)) — 12 жағдай: қалыпты, күрделі, екіұшты, қате алғышарт, мәдени ерекшелік, кері байланыс, чат, сүзгі. Нақты ЖИ кілтімен қайта жүгіртіп, «қолмен бағалау» жолдарын толтырыңыз.
3. **Браузерлік сценарий** (`npm run smoke`) — кіруден бастап бағалауға дейін.
