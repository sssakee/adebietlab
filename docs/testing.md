# Тестілеу

Үш деңгей:

1. **Unit-тесттер** (`npm test`, `src/lib/*.test.ts`) — ЖИ-сіз ережелер, ЖИ жауабының схемасы мен тазалауы.
2. **ЖИ тест жағдайлары** (GitHub Actions → AI eval, не `npm run ai:eval` → [ai-eval-results.md](ai-eval-results.md)) — 21 жағдай: генератор, кері байланыс, чат, сөздік, кейіпкермен сұхбат, оқу жоспары, шығармашылық пікір, сүзгі. Шын модельмен төрт рет жүгірді, қолмен бағалауы — [ai-test-report.md](ai-test-report.md).
3. **Браузерлік сценарий** (`npm run smoke`) — кіруден бастап бағалауға дейін.
4. **Кітапхана шығармалары** (`npm run ai:works` → [works-eval-results.md](works-eval-results.md)) — әр шығарма бойынша ЖИ тапсырма жасай ала ма.

## Кітапханаға қосылған 20 шығарма: толық цикл (барлығы өтті)

Әр шығарма үшін браузерде: оқушы шығарма бетін ашады (толық мәтінге сілтеме бар) → мұғалім «кітапханадан шығарма таңдаңыз» арқылы тапсырма жасайды (әдістер кезекпен: Блум, синквейн, тест, Венн) → бекітеді → сыныпқа береді → оқушы бәріне жауап беріп тапсырады → мұғалім бағалайды → оқушы «Бағаланды» дегенді көреді. Оқиға желісі бар екі шығармада («Қорқыт ата туралы аңыздар», «Әке мен бала») құрал да тексерілді. 20 / 20 өтті, беттерде JavaScript қатесі жоқ (демо генератор, `AI_MOCK`). Шын модельмен (Gemini Flash-Lite) нәтиже — [works-eval-results.md](works-eval-results.md): 23 / 30. Өтпеген 7-еуінің бәрі Венн диаграммасы әдісі: бір шығарманың сипаттамасында салыстыратын екінші нысан жоқ, сондықтан модель тапсырма ойдан құрамай, «материал жеткіліксіз» деп дұрыс жауап берді. Блум, синквейн, тест әдістері 23 / 23. Венн үшін мұғалім екі кейіпкер не екі шығарма туралы материал қояды.
