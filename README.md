# ӘдебиетLab

**5–11 сынып оқушылары мен қазақ әдебиеті мұғалімдеріне арналған зертхана.**

5–11 сынып оқушылары мен қазақ әдебиеті мұғалімдеріне арналған әдебиет зертханасы (MVP).

## Не істей алады

**Оқушы**
- сынып коды, аты және 4 цифрлы PIN арқылы кіреді (телефон, мекенжай сұралмайды);
- шығармалар кітапханасы: іздеу, сынып пен жанр бойынша сүзгі;
- **Өлең өлшегіш**: буын санау, буынға бөлу, ұйқасты белгілеу, өлшем мен ұйқас түрін тексеру, «Өз мәтініңді өлше» (ЖИ-сіз, ережемен);
- **Кейіпкер картасы**: байланыс қосып, дәлел жазады, эталонмен салыстырылады;
- **«Егер...» тәжірибесі**: болжам, дәлел, өзін-өзі тексеру, сыныптастар болжамын қолдау;
- мұғалімнің тапсырмаларын орындау: жабық сұрақтар бірден тексеріледі;
- **«Сұрағың бар ма?»** — Қырантай ЖИ көмекшісі: беттің контекстін біледі, мұғалім қойған режиммен жұмыс істейді;
- **Оқиға желісі** — оқиғаларды ретке қойып, сюжет элементін таңдайды (ережемен тексеріледі);
- дұрыс жауапқа шағын дыбыс (әдепкіде өшірулі, мәзірден қосылады) пен анимация; жүйеде «қозғалысты азайту» қосулы болса, анимация өшеді;
- телефонда төменгі мәзір, қараңғы режим (құрылғы баптауы бойынша), әр батырмада күту белгісі мен нәтиже хабары;
- ұпай («ашылым»), деңгей (Балапан → Қанаттанған → Қыран), қатарынан күндер, белгілер.

**Мұғалім**
- тіркеледі, сынып ашады, жүйе 6 таңбалы код береді;
- **әдіс + материал → тапсырма**: TXT/DOCX файл, мәтін немесе кітапханадағы шығарма; ЖИ JSON түрінде тапсырма жасайды, zod тексереді;
- тапсырмаларды қарап, өңдеп, жойып, бекітеді; бекітпейінше оқушы ештеңе көрмейді;
- сыныпқа мерзіммен және ЖИ режимімен береді (ЖИ-сіз / Шектеулі / Рұқсат етілген);
- өз әдісін қосады (атауы, сипаттамасы, мысал тапсырма) — генератор оны да қолданады;
- нәтижелер кестесі, «Сынып қайда қиналды», жиі қателер, Excel-ге (CSV) жүктеу;
- ашық жауаптарға ЖИ ұсыныс балы мен пікір жазады, соңғы балды мұғалім қояды;
- «Егер...» жұмыстарын 3 критериймен (0–2) бағалайды.

## Үш байланысқан ЖИ функциясы

1. **Тапсырма генераторы** — мұғалім материалы + әдіс → құрылымды тапсырмалар (`src/app/mugalim/actions.ts` → `generateTasks`).
2. **Ашық жауапқа кері байланыс** — оқушы жауабы + критерий → ұсыныс балы мен пікір (`suggestScores`).
3. **«Сұрағың бар ма?» чаты** — оқушы сұрағы + бет контексті + мұғалім режимі → ағынмен жауап (`src/app/api/chat/route.ts`).

Бірінші функцияның шығысы екіншісі мен үшіншісінің кірісі болады: генератор жасаған тапсырманы оқушы орындайды, чат сол тапсырманың режимі мен контекстін алады, ал ашық жауапты ЖИ сол тапсырманың критерийімен тексереді. Сызбасы: [docs/io-diagram.md](docs/io-diagram.md).

## Технологиялар

Next.js 16 (App Router), TypeScript (strict), Tailwind CSS 4, PostgreSQL (`postgres` кітапханасы; Supabase-те де жұмыс істейді), zod, mammoth (DOCX), Vitest, JUZ40 FONTS шрифты.

ЖИ провайдері бір файлда тұр (`src/lib/ai/index.ts`) және OpenAI-үйлесімді API арқылы жұмыс істейді:

| `AI_PROVIDER` | Кілт қайдан алынады | Модель мысалы |
| --- | --- | --- |
| `gemini` | [aistudio.google.com](https://aistudio.google.com) → Get API key (тегін тариф) | `gemini-flash-lite-latest` (тегін тарифте Flash-тың шегі күніне 20 сұрау ғана) |
| `groq` | [console.groq.com](https://console.groq.com) → API Keys (тегін тариф) | `openai/gpt-oss-120b` |
| `openai` | кез келген OpenAI-үйлесімді сервис, `AI_BASE_URL` қажет | — |

`AI_MOCK=true` болса (немесе кілт жоқ болса) ЖИ шақырылмайды: тапсырмалар мен жауаптар ережемен жасалады, сайт толық жұмыс істейді.

> Тегін тарифтерде провайдер сұрау мазмұнын өз өнімін жақсартуға қолдануы мүмкін. Сондықтан чатқа жазылған жеке дерек (телефон, пошта, мекенжай, ЖСН) ЖИ-ге жіберілмейді (`src/lib/safety.ts`), ал чат мәтіні дерекқорда мүлде сақталмайды.

## Жергілікті іске қосу

Керек: Node.js 20+, PostgreSQL 14+.

```bash
npm install
cp .env.example .env.local          # AUTH_SECRET-ке кездейсоқ жол жазыңыз: openssl rand -base64 32
createdb adebietlab                  # немесе Supabase-тегі дерекқор
npm run db:setup                     # кестелер + демо деректер
npm run dev                          # http://localhost:3000
```

Демо аккаунттар:
- мұғалім: `demo@adebietlab.kz` / `demo1234`
- оқушы: сынып коды `LAB7QA`, аты `Айару` (не `Дана`, `Мирас`), PIN `1234`

## Деплой (Vercel + Supabase)

1. [supabase.com](https://supabase.com) → New project (аймағы: Frankfurt). Ашылған соң **SQL Editor** → `db/supabase.sql` файлының бүкіл мазмұнын қойып → **Run**. Бұл кестелер мен демо деректерді жасайды (файлды `npm run db:setup && npm run db:sql` қайта шығарады).
2. Supabase → **Connect** → **Transaction pooler** жолын көшіріңіз (порты 6543). `[YOUR-PASSWORD]` орнына жоба ашқанда қойған құпиясөзді жазыңыз.
3. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key** (тегін Gemini кілті).
4. [vercel.com/new](https://vercel.com/new) → `adebietlab` репозиторийін Import → **Environment Variables**:
   `DATABASE_URL` (2-қадам), `AUTH_SECRET` (кез келген 40 таңбалы кездейсоқ мәтін), `AI_PROVIDER=gemini`, `AI_API_KEY` (3-қадам), `AI_MODEL=gemini-flash-lite-latest`. Сосын **Deploy**.

Жаңа шығармалар қосылғанда (бар деректерге тимейді): Supabase → **SQL Editor** → `db/works-update.sql` файлының бүкіл мазмұнын қойып → **Run**.

Кілттерді ешқашан кодқа не чатқа жазбаңыз — тек `.env.local` пен Vercel баптауларына. Кілт берілмесе, сайт демо режимде (`AI_MOCK`) жұмыс істейді.

Ескерту: Vercel сұрау денесін ~4,5 МБ-пен шектейді, сондықтан онда үлкен DOCX жүктеу кесілуі мүмкін.

## Қауіпсіздік

- Браузер дерекқорға тікелей қосылмайды; әр бет пен әр server action рөлді серверде тексереді (`requireRole`). Барлық кестеде RLS қосулы, саясаты жоқ: Supabase-тің ашық REST/anon кілті ештеңе көрмейді.
- Cookie-де тек қол қойылған пайдаланушы id-і мен мерзімі (30 күн, қолтаңбаның ішінде); рөл дерекқордан оқылады.
- Кіру шектеулі: бір аккаунтқа 5, бір IP-ге 30 қате әрекет / 15 минут (`src/lib/limit.ts`). 4 цифрлы PIN-нің 10 000 ғана нұсқасы бар, шексіз сынауға болмайды.
- Қорғаныс тақырыптары: HSTS, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy` (`next.config.ts`).
- Құпиясөз бен PIN scrypt-пен хэштеледі.
- Мұғалім оқушының чатын оқи алмайды: чат мәтіні сақталмайды, тек күндік сұрақ саны мен токен шығыны (`ai_usage`).

## Авторлық құқық

Шығарма мәтіні жадтан жазылмайды және кітапханалардан көшірілмейді. Кітапханада тек ТЗ-да тексерілген «Қыс» өлеңінің 1-шумағы бар. Әр шығарманың қысқаша сипаттамасы өзіміз жазған мәтін, ал толық мәтінге [adebiportal.kz](https://adebiportal.kz) бетіне сілтеме беріледі: порталдың пайдаланушы келісімі (2.3–2.6) мәтіннің үштен бірінен артығын көшіруге тек жазбаша рұқсатпен жол береді.

Қоғамдық игілік: автор қайтыс болғаннан кейін 70 жыл; репрессияға ұшырап, кейін ақталған автор үшін 70 жыл ақталған жылдан саналады (Авторлық құқық туралы заң, 28-бап, 7-тармақ). Сондықтан Байтұрсынұлы, Жұмабаев, Шәкәрім, Әуезов шығармалары әлі қорғалған: оларға тек ақпарат беріледі. Сыныптарды оқулықпен тексеру керек — `scripts/seed-data.ts` ішіндегі `TODO`.

JUZ40 FONTS шрифты TypeType компаниясының лицензиясымен (EULA) қолданылады, сондықтан репозиторий жабық.
