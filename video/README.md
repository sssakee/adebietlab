# ӘдебиетLab — промо-видео (Remotion)

1920×1080, 30 кадр/с. Сценарий — `SCRIPT.md`, диктор мәтіні — `voiceover.md`.

```
cd video && npm install
npm run studio        # браузерде алдын ала қарау
npm run render        # әуенді жасап, out/adebietlab.mp4 шығарады
```

- **Экрандар** (`public/shots`) — сайттың өзі, демо деректермен: `npm run db:setup && npm run build && npm start`, сосын `node video/capture.mjs`. Скрипт алдымен үш оқушының атынан тапсырма орындайды (нәтиже мен аналитика бос болмауы үшін), экран сайын элементтердің орнын `src/boxes.json`-ға жазады — камера соған жақындайды. Демо ЖИ жауабындағы «(Демо режим…)» белгісі түсірерде алынады.
- **Әуен** (`public/music.wav`, репозиторийде жоқ) — сайттың өз домбыра әуені (`src/lib/music.ts`), `scripts/music.ts` файлға синтездейді. Лицензия керек емес.
- **Диктор** (`public/vo`, `src/vo.json`) — ElevenLabs, жоба иесінің клондалған дауысы (eleven_v3, kk, эмоция тегтері): `ELEVENLABS_API_KEY=… node scripts/vo-generate.mjs ./ [01,02]`. Мәтін `voiceover.md`-де; `{n}` белгілерінің уақыты (with-timestamps) `vo.json`-ға жазылады, камера мен субтитр соған байланады. Сахна ұзақтығы дауысқа қарай өзі есептеледі.
- **Дыбыс эффектілері** (`public/sfx`) — `scripts/sfx.ts` сайттың өз дыбыстарын синтездейді (басу, ұшқын, вуш…).
- **Браузер**: `remotion.config.ts` Playwright-тың chrome-headless-shell-ін қолданады, басқа жерде `REMOTION_BROWSER` арқылы беріңіз.
- Remotion лицензиясы: жеке адам мен 3 адамға дейінгі компанияға тегін, үлкен компанияға ақылы лицензия керек.
